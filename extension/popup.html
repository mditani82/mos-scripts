Mo's Scripts

  • + Add a script: optional alias, then pick the .sh file. No alias → file name is used.
  • Search filters by alias or path. ↑↓ select, Enter runs.
  • Recent first: last-run scripts sort to the top.
  • Click a row to see its full path and terminal output (live while running). Hover for ✎ to rename or ✕ to remove (stops it if running; file is untouched).
  • PROD = path contains /prod/ or /production/. Needs a second Confirm within 3s.
  • Long-running scripts (tunnels, servers) keep going in the background after 10s (badge ON). Any running script shows ● running and a Stop button.
  • Output of the last run shows below the list. Full logs: ~/.mos-scripts/logs/<alias>.log
  • Scripts run in their own folder with your login shell's PATH. They can't prompt for input.

  1. Download the helper from the latest release and unzip it.
  2. In Terminal, run:
    cd ~/Downloads/mos-scripts-helper && ./install.sh
  3. This screen switches to your scripts by itself once it's installed.
